# AI Tools Lab

## Project Description

AI Tools Lab is a Python project created for learning GitHub,
version control, sorting algorithms, and utility functions.

The project contains:
- A bubble sort algorithm
- Palindrome checking
- Word counting
- Celsius to Fahrenheit conversion
